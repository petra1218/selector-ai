extension-first

Selector moved to a Chromium extension

The bookmarklet install flow is no longer the primary path. Install Selector as an unpacked Chromium extension, then use the toolbar icon to start it on the current page.

Install
  1. Open your browser's extensions page: chrome://extensions, edge://extensions, or brave://extensions.
  2. Enable Developer mode.
  3. Click Load unpacked.
  4. Select this project folder.
  5. Pin Selector to the toolbar for direct access.
Launch

Main path: click the Selector toolbar icon to activate the selector immediately on the active tab.

Popup is a secondary entry point. You can open it with Alt+Shift+S or Command+Shift+S on macOS.
Migration note

This page no longer builds bookmarklet assets. If you were using the old bookmark flow, switch to the unpacked extension install above.
