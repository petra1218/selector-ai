# Security Policy / 安全说明

[中文](#中文) | [English](#English)

## 中文

如果你发现 Selector 存在安全问题，请先私下反馈(petra1218@gmail.com)，不要直接公开提交 issue。

建议反馈内容包括：

- 问题简述
- 影响范围和可能后果
- 复现步骤
- 如有帮助，可附上截图或相关 prompt 输出

如果你准备将仓库公开发布，建议在正式发布前把这里替换成你的真实安全联系渠道。

## English

If you find a security issue in Selector, please report it privately before opening a public issue(petra1218@gmail.com).

Include:

- a short description of the issue
- impact and affected scope
- reproduction steps
- screenshots or copied prompt output if they help explain the risk

Before publishing the repository, replace this section with your actual private security contact channel.
